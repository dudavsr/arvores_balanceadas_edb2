# arvores_balanceadas_edb2

TUTORIAL DE UTILIZAÇÃO DO SISTEMA

Para funcionar corretamente, faça o seguinte procedimento:

Primeiramente, rode a primeira célula (a maior, que contém basicamente todo o código)
Depois, rode a segunda, que pega o arquivo criado na primeira célula compila e cria um executável
Finalmente, rode a terceira célula para executar.
Com isso, irá aparecer o sistema de árvores balanceadas, tendo como opções:
1. Árvore AVL
2, Árvore Rubro-Negra
3. Executar teste automático.
Para digitar, clique antes no espaço após “Por favor, escolha o tipo de árvore, digite o número: ” Digite o número da opção escolhida.
A partir disso, você irá automaticamente para o menu de ações do tipo de árvore escolhida, selecione novamente o que deseja fazer. 

Para remover, inserir, ou buscar, adicione um número por vez.
A árvore começa vazia.

Caso tenha selecionado executar o teste automático, você já recebe os resultados.
